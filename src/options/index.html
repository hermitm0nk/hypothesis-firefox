By default, the extension button displays the number of annotations found on the pages you visit. Disable this if you find the badge distracting or if you do not wish the extension to make requests to the Hypothesis service for this data.

The theme applies to open sidebars immediately.

Keyboard shortcut

Press Alt+Shift+H to toggle the sidebar. To change it, open Firefox Add-ons and Themes, select the gear menu, then Manage Extension Shortcuts.
